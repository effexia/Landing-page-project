# Landing-page-project

A responsive-looking landing page built from a provided design as part of
[The Odin Project](https://www.theodinproject.com/) Foundations course.

## Built With

- HTML5
- CSS3 (Flexbox)
- Google Fonts (Roboto)

## What I Learned

- Building a full page layout from a design mockup
- Using Flexbox to align and space sections, columns and cards
- Managing default margins and spacing between elements
- Working section by section and committing changes regularly with Git
